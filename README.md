# GitHubDemo

A beginner number-guessing game written in Java.

## Run on a MacBook

Install a JDK, then open Terminal in this folder. Confirm Java is installed with `java -version` and `javac -version`.

Compile the source file and run its class:

```sh
javac NumGuess.java
java NumGuess
```

The game chooses a number from 1 through 100. Enter guesses until you find it.

To check that the program compiles, run:

```sh
bash scripts/check-java.sh
```
